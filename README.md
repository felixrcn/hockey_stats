# hockey_stats
Exploration of hockey statistics and machine learning with python libraries.

## Team prediction
The first model predicts a team's "score" in the standings using the performances of their best players.

## Individual prediction
The second model uses individual statistics to predict points. The goal is to know what to tell a player so they score more points allowing  the team more wins.

## Expected goals
Using play-by-play data form the 2024-2025 season, I elaborated a simple expected goals model. I used logistic regression with log loss to
get a first look at the data and used a Ridge regression to back a simple recommendation to a (imaginary) NHL coach.
